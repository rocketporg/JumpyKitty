# JumpyKitty

This is a slightly modified version of one of my old games from the Google play store (delisted now). It's just a simple little infinite scroller written using MonoGame, with a little kitty jumping on platforms to avoid the water. Have fun! Only thing I've left out is the audio effects as these were paid assets and not mine...

Now open source and an example of a simple game written using Monogame and Monogame Extended :)
